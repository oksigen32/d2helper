# D2Helper

Личный дневник игрока Dota 2: актуальная мета и билды (OpenDota), запись ПТС, тренировки, наблюдения, цели.

**Открыть онлайн:** https://oksigen32.github.io/d2helper/

**Приложение для Windows:** скачай `D2Helper.zip` в разделе [Releases](https://github.com/oksigen32/d2helper/releases/latest), распакуй и запусти `D2Helper.exe`.
Обновления приходят автоматически. Все записи хранятся только на твоём компьютере.
